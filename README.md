Quantified Self Project: Hypothetical Betting Data

My project looked at my hypothetical betting data from December 1st to March 31st. I wanted to determine if I could predicit whether a bet would win or lose.
To run my project clone the repository open data_story.ipynb and run the notebook cells. 
My project is organized:
1. An Introduction to the project
2. The data cleaning process including merging a 2nd table
4. The data aggregated
5. Two hypotheses about the data with accompanying graphs
6. Data classification in preparation for machine learning
7. Correlation matrix to success
8. a kNN classifier
9. a decision tree
10. My conclusion
